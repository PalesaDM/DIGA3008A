3 March, 2025

User alignment refers to the manner in which elements of your website layout are positioned. This includes images, text etc. At this very moment,I want my user alignment to be simple but neat. It should not have a cluttered effect and should reflect readability as well as usability.

Mapping Out Site Content, Experience and Interface Elements

Content: The content that will be on the website includes weekly blogs, essays, and the content on the portfolio page.

Homepage: This will have a consistent navigation bar,website name, creator name,footer that has creator name, date, email and github link.

About: Includes information about the website, the creator and when the website was launched

Blog: Includes my weekly blog posts

Portfolio: Previous work or projects

Essays: This will have two of my essays

Design: My wireframes, styleguide with the colour palette, text choices..etc will be on the design page.

Experience:

Interactivity between the user and website should be effective and flow well.

Navigation tools to move from one page to another will be available as well as a smooth navigation for mobile devices and laptops.

Interface Elements:

These may include buttons specifically for blog page, scroll bars, animated images, search bar, dark mode button

The above exercise helps me understand and plan my structure and URL scheme more, allowing room for changes every week and improvement. It allows me to engage with the good practice of semantic markup in order to improve accessibility for users and applying or simple practices that will be easy to maintain.
