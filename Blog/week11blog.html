Decolonialism and My Code

When I look at how my code functions in the context of decolonialism, I come to the realisation that certain decisions — such as the use of language, images, accessibility, and user flow — have a strong relation to either strengthening or challenging existing power dynamics.

Going through my code, I have understood that I need to make use of inclusive language for individuals who do not understand English, in order to promote inclusivity. My layout and design structure should also be accessible to individuals using different devices and with different abilities. Implementing these two elements will ensure that my work respects diverse users and avoids exclusivity.

Development Process with JavaScript

The very first thing that I had to do while adding JavaScript to my website was make changes to my HTML by adding classes to easily target elements with JavaScript. I am currently working towards adding more interactive elements such as toggling menus and dynamic elements for my website.

This has helped me streamline my interaction design by improving user experience. I'm now able to use instant form validation and enhance navigation by making it smoother and animating specific elements.
